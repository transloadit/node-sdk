Require zod 4.6.7 or later, which fixes advisory GHSA-mrhx-c7xc-m3w5 in Zod 4's core. The schemas
parse the same input to the same output and the Zod 3 export is unchanged. With Zod 4.6, the Zod 4
declarations spell some schema classes differently (for example `ZodInstanceOf` instead of
`ZodCustom` for `z.instanceof`), and `z.toJSONSchema` returns Zod 4.6's output, such as
`type: ['string', 'null']` where Zod 4.4 used `anyOf`.
