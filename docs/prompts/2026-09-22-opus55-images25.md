# Opus 5.5 and Images 2.5

## Why

Expose the newly supported backend models and default `image generate` to the faster Images 2.5
Flare variant. Keep Images 2.5 Sunburst available explicitly for precision-focused work. Preserve
existing explicit model selections, Astra chat defaults, Sonnet image descriptions, and medium
Assembly Instructions compilation effort.

## Rollout prerequisite

Do not publish this default change until API2's matching Images 2.5 support, usage-based billing,
and provider smoke checks have been deployed. The SDK sends the exact model ID to API2; it does
not emulate or silently substitute unavailable models.

Sources: [Opus 5.5](https://platform.claude.com/docs/en/models/opus-5-5/overview),
[Images 2.5 Flare](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare), and
[Images 2.5 Sunburst](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst).
